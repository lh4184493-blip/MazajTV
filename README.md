# مزاج TV (MazajTV)

تطبيق أندرويد لمشاهدة قنوات بث مباشر عبر رابط قائمة تشغيل M3U/M3U8.

## ⚠️ ملاحظة مهمة
هذا التطبيق **لا يحتوي على أي روابط قنوات مدفوعة أو مرخصة** (مثل beIN Sports أو غيرها).
التطبيق مصمم ليكون "فارغ" من المحتوى، ويعتمد كلياً على:

1. رابط M3U تدخله أنت بنفسه من شاشة الإعدادات (يجب أن يكون رابطاً تملك ترخيصاً/اشتراكاً قانونياً لاستخدامه).
2. قائمة تجريبية افتراضية (Demo) لأغراض الاختبار فقط، تستخدم بثوث حرة ومفتوحة رسمياً من Apple وGoogle لاختبار مشغلات الفيديو، وليست قنوات تلفزيونية.

## البنية التقنية
- **Kotlin** + **Media3 ExoPlayer** لتشغيل البث (HLS/DASH/MP4).
- **OkHttp** لجلب وتحليل ملفات M3U.
- **RecyclerView** لعرض قائمة القنوات بتصميم بطاقات (Cards).
- الألوان: خلفية `#050505`، بطاقات `#121212`، لون مميز ذهبي `#FFD700`، نص أبيض، وشارة LIVE حمراء.

## الشاشات
| الشاشة | الوظيفة |
|---|---|
| Splash | شاشة البداية بالشعار |
| Main | قائمة القنوات (من M3U أو تجريبي) |
| Player | تشغيل القناة المختارة |
| Settings | إدخال/تغيير رابط M3U |

## كيف أشغّل مشروعي الخاص بمحتوى قانوني؟
1. افتح التطبيق → اضغط أيقونة الإعدادات ⚙️
2. الصق رابط M3U الخاص بك (من مزود اشتراك رسمي تملك حق استخدامه)
3. اضغط "حفظ" — راح ترجع القائمة الرئيسية وتُحمّل قنواتك تلقائياً

## البناء (Build)
1. افتح المجلد في Android Studio (Hedgehog أو أحدث)
2. حدّث `local.properties` بمسار SDK عندك
3. Sync Gradle ثم Run على جهاز/محاكي
